خیلی خوب، حالا برات **مستند کامل API** می‌سازم:

• دسته‌بندی‌شده  
• همراه با `curl` برای هر اندپوینت  
• همراه با Body و Response JSON نمونه  
• پوشش کامل:  
  - Chat endpoints  
  - Chat actions  
  - Message endpoints  
  - Message actions  
  - WebSocket endpoints

---

# بخش 1 — Chat Endpoints  
(لیست، ساخت، جزئیات، آپدیت، حذف)

## 1.1 لیست چت‌ها  
**GET /chats/**

### curl
```
curl -X GET https://yourdomain.com/api/chats/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response نمونه
```
[
  {
    "id": 12,
    "name": "My Group",
    "chat_type": "group",
    "is_private": false,
    "last_message": "hello",
    "last_message_time": "2026-05-08T12:41:43Z",
    "unread_count": 5
  }
]
```

---

## 1.2 ساخت چت  
**POST /chats/**

### curl
```
curl -X POST https://yourdomain.com/api/chats/ \
  -H "Authorization: Bearer <TOKEN>" \
  -F "name=Group 1" \
  -F "chat_type=group" \
  -F "description=Test group"
```

### Request body
```
{
  "name": "Group 1",
  "chat_type": "group",
  "description": "Test group",
  "username": "group001"
}
```

### Response
```
{
  "id": 41,
  "name": "Group 1",
  "chat_type": "group",
  "is_private": false,
  "description": "Test group",
  "member_count": 1,
  "user_role": "creator",
  "settings": {
    "only_admins_can_send": false,
    "slow_mode": 0,
    "description": null
  }
}
```

---

## 1.3 جزئیات چت  
**GET /chats/{id}/**

### curl
```
curl -X GET https://yourdomain.com/api/chats/41/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
{
  "id": 41,
  "name": "Group 1",
  "chat_type": "group",
  "is_private": false,
  "description": "Test group",
  "member_count": 5,
  "user_role": "member",
  "settings": {
    "only_admins_can_send": false,
    "slow_mode": 0,
    "description": null
  }
}
```

# بخش 2 — Chat Actions  
(اعضا، پیام‌ها، ارسال پیام، اضافه عضو، حذف عضو، جوین، لِیو)

---

## 2.1 دریافت پیام‌های چت  
**GET /chats/{id}/messages/**

```
curl -X GET https://yourdomain.com/api/chats/41/messages/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
[
  {
    "id": 101,
    "sender": 3,
    "sender_name": "John Doe",
    "content": "hello",
    "sent_at": "2026-05-08T12:41:43Z",
    "is_edited": false,
    "can_edit": true,
    "can_forward": true
  }
]
```

---

## 2.2 ارسال پیام در چت  
**POST /chats/{id}/send_message/**

### curl
```
curl -X POST https://yourdomain.com/api/chats/41/send_message/ \
  -H "Authorization: Bearer <TOKEN>" \
  -F "content=Hello world"
```

### Response
```
{
  "id": 188,
  "sender": 3,
  "content": "Hello world",
  "sent_at": "2026-05-08T12:44:10Z",
  "is_edited": false
}
```

---

## 2.3 دریافت لیست اعضا  
**GET /chats/{id}/members/**

### curl
```
curl -X GET https://yourdomain.com/api/chats/41/members/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
[
  {
    "user": 3,
    "user_info": {
      "id": 3,
      "username": "john",
      "email": "john@example.com"
    },
    "role": "member",
    "is_admin": false
  }
]
```

---

## 2.4 اضافه کردن عضو  
**POST /chats/{id}/add_member/**

### curl
```
curl -X POST https://yourdomain.com/api/chats/41/add_member/ \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"user_id": 7}'
```

### Response
```
{"status": "member added"}
```

---

## 2.5 حذف عضو  
**DELETE /chats/{id}/remove_member/**

### curl
```
curl -X DELETE https://yourdomain.com/api/chats/41/remove_member/ \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"user_id": 7}'
```

### Response
```
{"status": "member removed"}
```

---

## 2.6 جوین کانال  
**POST /chats/{id}/join/**

```
curl -X POST https://yourdomain.com/api/chats/55/join/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
{"status": "joined channel"}
```

---

## 2.7 لِیو چت  
**POST /chats/{id}/leave/**

```
curl -X POST https://yourdomain.com/api/chats/41/leave/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
{"status": "left chat"}
```

# بخش 3 — Message Endpoints  
(نمایش، ساخت، حذف)

## 3.1 لیست تمام پیام‌هایی که کاربر دسترسی دارد  
**GET /messages/**

```
curl -X GET https://yourdomain.com/api/messages/ \
  -H "Authorization: Bearer <TOKEN>"
```

---

## 3.2 مشاهده یک پیام  
**GET /messages/{id}/**

```
curl -X GET https://yourdomain.com/api/messages/188/ \
  -H "Authorization: Bearer <TOKEN>"
```

Response مشابه MessageSerializer است.

---

# بخش 4 — Message Actions  
(ادیت، فوروارد، حذف)

---

## 4.1 ادیت پیام  
**PUT /messages/{id}/edit/**

### curl
```
curl -X PUT https://yourdomain.com/api/messages/188/edit/ \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"content": "Updated text"}'
```

### Response
```
{
  "id": 188,
  "content": "Updated text",
  "is_edited": true
}
```

---

## 4.2 فوروارد پیام  
**POST /messages/{id}/forward/**

### curl
```
curl -X POST https://yourdomain.com/api/messages/188/forward/ \
  -H "Authorization: Bearer <TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"chat_id": 41}'
```

### Response
```
{
  "id": 209,
  "content": "Updated text",
  "forward_from": 188
}
```

---

## 4.3 حذف پیام  
**DELETE /messages/{id}/delete/**

### curl
```
curl -X DELETE https://yourdomain.com/api/messages/188/delete/ \
  -H "Authorization: Bearer <TOKEN>"
```

### Response
```
{"status": "deleted"}
```

---

# بخش 5 — WebSocket Endpoints  
دو WebSocket داری:

## 5.1 دریافت پیام‌های زنده چت  
**ws://yourdomain/ws/chat/{chat_id}/**

```
ws://yourdomain.com/ws/chat/41/
```

### پیام ورودی نمونه:
```
{
  "type": "message",
  "content": "Hello via WS"
}
```

---

## 5.2 نوتیفیکیشن‌های عمومی  
**ws://yourdomain/ws/notifications/**

```
ws://yourdomain.com/ws/notifications/
```
